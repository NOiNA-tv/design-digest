# Design Digest

A weekly, phone-first digest of design & animation newsletters (Gmail Social tab), curated by Claude every Sunday.

- `index.html` – the app (tabs per category, EN / Hebrew toggle, virality badges)
- `data/index.json` – list of issues, newest first
- `data/YYYY-MM-DD.json` – one file per weekly issue

Live at https://noina-tv.github.io/design-digest/
